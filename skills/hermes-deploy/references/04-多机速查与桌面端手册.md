# 04 · 多机配置 / 路径 / 桌面端 / 故障速查（拿来即用）

> 用途：不同 Windows 版本、不同磁盘与权限的电脑，照此表装 Hermes CLI 与桌面端。
> 依据：官方 Windows 原生指南 + 中文社区镜像 install.ps1 + EvoLink 配置指南（2026-10 全网核对）。

---

## 一、不同电脑版本的环境要求

| 环境 | 要求 | 说明 |
|:---|:---|:---|
| Windows 版本 | **Windows 10 / 11**（原生支持） | 无需 WSL2、Cygwin、Docker |
| 架构 | x64（amd64）为主；ARM 用 3.11 ARM 构建 | 远控机多为 x64 |
| 权限 | **非管理员即可** | 安装器落 `%LOCALAPPDATA%\hermes`，写用户目录 |
| 预装依赖 | **可不预装** Python/Node/Git | 安装器自带 uv 引导；已有则复用 |
| 网络 | 国内：走 `res1.hermesagent.org.cn` 镜像 | 海外/直连：`hermes-agent.nousresearch.com` |
| 磁盘 | 预留 ≥ 1–2 GB（Node/Git/venv） | 数据默认 `%LOCALAPPDATA%\hermes` |
| **macOS** | **macOS + Git/curl/tar/shasum** | 一行 `curl -fsSL https://hermes-agent.nousresearch.com/install.sh \| bash`；Python 要求 `>=3.14,<3.15`（PM 自备）；桌面端为 DMG，老机型慎用 |

> 想要 dashboard 内嵌终端（POSIX PTY）/Linux 语义 → 上 **WSL2**；纯 CLI 对话、TUI、消息网关、MCP、本地 Ollama 在原生 Windows 全可用。

## 二、安装路径速查（不同布局）

| 布局 | 代码位置 | 数据/配置 | hermes 命令 |
|:---|:---|:---|:---|
| **默认（推荐）** | `%LOCALAPPDATA%\hermes\hermes-agent` | `%USERPROFILE%\.hermes\`（`C:\Users\<u>\.hermes`） | `%LOCALAPPDATA%\hermes\bin`（已加用户 PATH） |
| 自定义 | `-InstallDir <路径>` | `-HermesHome <路径>` | 随安装器 |
| pip 手动（本项目历史） | `D:\Hermes\Python\Lib\site-packages` | `~/.hermes\` | `D:\Hermes\Python\Scripts\hermes.exe` |
| **macOS（POSIX 源码脚本）** | `~/.hermes/hermes-agent/` | `~/.hermes/`（`HERMES_HOME` 可覆盖） | `~/.local/bin/hermes` |

> ⚠️ 版本差异：官方新版文档把 Windows 数据目录写为 `%LOCALAPPDATA%\hermes\`；**实测 0.19.0 配置落在 `C:\Users\<u>\.hermes\`**。两边都找一下，或用 `HERMES_HOME` 显式指定。

**关键文件（无论哪条路线，配置都在这）**：
- `~/.hermes/config.yaml` → **模型/端点/兼容模式（`model.base_url` 在这）**
- `~/.hermes/.env` → **API Key（机密）**
- `~/.hermes/`：`cron/sessions/logs/memories/skills/pairing` 子目录

> 红线：数据**默认不进 C 盘用户文档区**（在 `%LOCALAPPDATA%\hermes` 与 `~\.hermes`）；pip 手动路线若用 D 盘则全在 D 盘。

## 三、Hermes 桌面端（GUI）安装路径与方法 ★ 2026-10-02 实战修正

桌面端 = 桌面 App（Electron 打包），**与 CLI 共享同一代码/数据目录**，可互切。

### ❌ 已证伪的两条路（别再试）
| 做法 | 结果 |
|:---|:---|
| `hermes desktop`（CLI 子命令） | ❌ 报 `Desktop GUI source not found: ...\site-packages\apps\desktop` |
| pip 装完再补桌面端 | ❌ pip 包**根本不含** `apps/desktop` 源码，无解 |

### ✅ 唯一正解：官方安装器 + `-IncludeDesktop`

```powershell
& ([scriptblock]::Create((irm https://hermes-agent.nousresearch.com/install.ps1))) -IncludeDesktop -NonInteractive
```
- `-IncludeDesktop`：**加桌面端构建阶段（默认不加，只给 CLI）**
- `-NonInteractive`：跳过交互式 setup
- 产物：`%LOCALAPPDATA%\hermes\hermes-agent\apps\desktop\release\win-unpacked\Hermes.exe` + 桌面/开始菜单 `Hermes.lnk`

### 其它官方形态（按平台）
| 平台 | 形态 | 关键限制 |
|:---|:---|:---|
| Windows | **MSIX / App Installer**（自包含包） | 要求 **Win11 22H2+**；首启无需克隆/编译 |
| Windows | `Hermes-Setup.exe` | 引导安装程序，本质是下载并配置源码 |
| Windows | 源码脚本 + `-IncludeDesktop` | 通用，Win10/11 均可（本手册主推） |
| macOS | **DMG 包** → 拖进 Applications | 受 macOS 版本 + CPU 架构限制，老机型可能不支持 |
| macOS/Linux | `install.sh` | 只出 CLI，桌面端看是否另有参数（**待实测**） |

> 路径结论：**桌面端和 CLI 共用 `%LOCALAPPDATA%\hermes\hermes-agent`（代码）与配置目录**，不用各自再装一份。
> 装桌面端前的镜像三件套、残留目录、8787 端口三坑 → 见 `05-桌面端安装实战与国内镜像.md`。

## 四、模型/端点配置（★ 翻车核心，务必照做）

铁律：
- **Custom endpoint 端点写 `~/.hermes/config.yaml` 的 `model.base_url`**
- **`OPENAI_BASE_URL` 只对 `provider: openai-api` 生效，对 custom 无效**
- key 放 `~/.hermes/.env`（`OPENAI_API_KEY=`）

**向导一步到位（推荐）**：
```powershell
hermes model
# 选 Custom endpoint (0) → base_url / key / 模型名 / 兼容模式选 Chat Completions
```
向导自动写对 `config.yaml`+`.env`。

**手动（不想跑向导）**：`config.yaml`
```yaml
model:
  provider: custom
  default: <模型名>
  base_url: https://api.agnes-ai.cn/v1
  api_mode: chat_completions
```
`.env`：`OPENAI_API_KEY=<key>`

**命令行分写（自动分流到正确文件）**：
```powershell
hermes config set OPENAI_API_KEY <key>            # → .env
hermes config set OPENAI_BASE_URL https://api.agnes-ai.cn/v1  # 仅 openai-api 生效
# custom 端点请改 config.yaml 的 model.base_url
```

**会话内切换**：`/model custom:<模型名>`、`/model custom:<命名provider>:<模型>`

## 五、故障 → 解决（速查）

| 现象 | 原因 | 解决 |
|:---|:---|:---|
| `hermes` 命令找不到 | 没重开终端 / PATH 没刷新 | 重开 PowerShell；或手动把 `%LOCALAPPDATA%\hermes\bin` 加用户 PATH（pip 路线加 `D:\Hermes\Python\Scripts`） |
| `no API key` / provider not found | key 没进 `.env` 或端点没进 `config.yaml` | 重跑 `hermes model` 向导；确认 `model.base_url` 在 config.yaml |
| 端点连不上 / 请求 404 | 把端点塞进 `.env` 的 `OPENAI_BASE_URL`（custom 无效） | 端点改写到 `config.yaml` 的 `model.base_url` |
| `401 Unauthorized` | key 错/过期 | 核对 `.env` 的 key |
| `403 Forbidden` | key 无权限/过期 | 换有效 key |
| context length 报错 | 模型上下文 < 64K | 换大上下文模型（如 256K 的 agnes-3.0-flash） |
| UnicodeEncodeError / 中文乱码崩溃 | Windows 控制台非 UTF-8 | 安装器已设 CP_UTF8；异常时设 `PYTHONUTF8=1`，勿设 `HERMES_DISABLE_WINDOWS_UTF8` |
| `not a Hermes git checkout` | 直连版 InstallDir 已存在 | 换子目录，或改走国内镜像/PyPI 路线 |
| 装到一半卡住 | GitHub 限速（直连版） | 改用国内镜像 `res1.hermesagent.org.cn` 一行 |
| `hermes desktop` 报 `Desktop GUI source not found` | pip 包无 `apps/desktop` | 换官方 install.ps1 + `-IncludeDesktop`（见 §三） |
| 桌面端卡 "Waiting for Hermes backend" / `ECONNREFUSED 8787` | 多实例抢端口 | 杀 `*hermes*`/`*electron*` 进程后单实例启动 |
| `getaddrinfo ENOTFOUND npmmirror.com` | 用了裸域名 | 换 `registry.npmmirror.com`（含 `/-/binary/electron/`） |
| 更新后 provider/配置丢了 | schema 迁移未跑 | `hermes config check` → `hermes config migrate` |
| 缺 Node/ffmpeg/ripgrep 提示 | 依赖懒加载未补 | 不影响核心对话；要浏览器/语音再装（安装器可 `-ensure <dep>` 或自动提示） |

## 七、不同电脑"一键装"最小命令集（贴进远控即可）

**国内远程机（只装 CLI）**
```powershell
irm https://res1.hermesagent.org.cn/install.ps1 | iex   # 装 CLI+全套
# 重开终端后：
hermes model            # 选 Custom endpoint 配端点
hermes                  # 发 hi 验收
```

**国内远程机（要桌面端 GUI）** ★ 实战正解
```powershell
# 1) 先设国内镜像（Electron/electron-builder 二进制）
$env:npm_config_registry='https://registry.npmmirror.com'
$env:ELECTRON_MIRROR='https://registry.npmmirror.com/-/binary/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://registry.npmmirror.com/-/binary/electron-builder-binaries/'
# 2) 若有旧残留目录，先挪开
if (Test-Path "$env:LOCALAPPDATA\hermes\hermes-agent") { Move-Item "$env:LOCALAPPDATA\hermes\hermes-agent" "$env:LOCALAPPDATA\hermes\hermes-agent.bak" -Force }
# 3) 官方安装器 + 桌面端（唯一正解）
& ([scriptblock]::Create((irm https://hermes-agent.nousresearch.com/install.ps1))) -IncludeDesktop -NonInteractive
# 4) 配置 + 验收
hermes model            # Custom endpoint
hermes                  # 发 hi
```

**海外/直连**
```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

**已装 Python 想定目录（D 盘）**
