# 01 · 国内快速安装路线（v3 · 2026-10-02 桌面端修订）

> 结论先行：
> **首选 = 国内镜像一行 `irm https://res1.hermesagent.org.cn/install.ps1 | iex`**（中文社区维护、优先国内直连、默认精简外网依赖、自动装 uv+Python3.11+Node+Git+venv+PATH+setup）。
> **备选 = PyPI 直装**（npmmirror 装 Python + 清华镜像装 hermes-agent，适合已装 Python / 想精细控制目录）。
> 官方原生 `iex (irm https://hermes-agent.nousresearch.com/install.ps1)` 在海外/直连下功能最全。
> ⚠️ 官方 install.ps1 有**国内镜像版**（res1.hermesagent.org.cn），它优先走国内直连、不再死磕 GitHub 克隆——昨晚"install.ps1 国内不可用"的结论**仅针对 raw.githubusercontent 直连版**，镜像版已解决，故重新列为首选。
> ★ **要桌面端（GUI）→ 必须官方 `install.ps1 -IncludeDesktop`**（`hermes desktop` 与 pip 路线都装不出）。见 `05-桌面端安装实战与国内镜像.md`。

## 路线优先级（按国内、快、稳排序）

| 序 | 路线 | 一句话 | 适用 |
|:--|:-----|:-------|:-----|
| A（首选，仅 CLI） | 国内镜像 install.ps1 | `irm https://res1.hermesagent.org.cn/install.ps1 \| iex` | 远程机可从 0 装，国内网络 |
| B | 官方原生 install.ps1 | `iex (irm https://hermes-agent.nousresearch.com/install.ps1)` | 海外/直连、要全功能（浏览器/网关） |
| **B+（要 GUI）** ★ | 官方 install.ps1 + `-IncludeDesktop` | `& ([scriptblock]::Create((irm https://hermes-agent.nousresearch.com/install.ps1))) -IncludeDesktop -NonInteractive` | **需要桌面端**；先设 `ELECTRON_*` 国内镜像 |
| C（备选，仅 CLI） | PyPI 直装 | npmmirror 装 Python + 清华镜像 `pip install hermes-agent` | 已装 Python、要定目录、镜像 A/B 不可达 |
| D | macOS `install.sh` | `curl -fsSL https://hermes-agent.nousresearch.com/install.sh \| bash` | 苹果电脑（见 `06-macOS安装路线.md`） |

## ❌ 易翻车误区：raw.githubusercontent 直连版 install.ps1（历史经验）

官方直连版 `install.ps1` 依赖从 GitHub 克隆仓库。国内网络曾实测的问题（镜像版已绕过，列此防误用）：
- GFW 对 `raw.githubusercontent.com` 间歇放行，时通时断
- HTTP/2 传输被 RST 掐断（curl 报 92 PROTOCOL_ERROR / early EOF），需 `git -c http.version=HTTP/1.1` 才勉强能用
- 公共镜像站不可靠：`ghfast.top` 403、`gh-proxy.com` 429、`ghproxy.net` 4xx、`gh.ddlc.top` DNS 失败
- 若曾配置 `git config url.<x>.insteadOf` 指向失效镜像，会**劫持所有 clone 请求**（表现为全部 403），需清理 global + system 两层：
  ```bash
  git config --global --unset-all url.<镜像>.insteadOf
  git config --system --unset-all url.<镜像>.insteadOf
  ```
- 该路线的 `InstallDir` 不能预先存在（否则报 "not a Hermes git checkout"）

**结论：国内优先用镜像版（路线 A），不要直接跑 raw.githubusercontent 直连版。** PyPI 有包时可走路线 C。

## ✅ 路线 A：国内镜像一行（首选，从零装）

远程 PowerShell（或 Windows Terminal）执行：
```powershell
irm https://res1.hermesagent.org.cn/install.ps1 | iex
```
- 自动：装 uv、Python 3.11（免预装）、Node、PortableGit、克隆仓库、建 venv、分层 `pip install`、把 `hermes` 加进用户 PATH、跑 `hermes setup`。
- 默认精简浏览器/Chromium/WhatsApp 等外网依赖，核心最稳。
- 装完**关闭当前 PowerShell，重开一个**，输入 `hermes` 验证。
- 可选参数（scriptblock 形式）：`-SkipSetup`（跳过向导，模型单独配）、`-Branch main`、`-HermesHome`/`-InstallDir` 自定义目录。
  ```powershell
  & ([scriptblock]::Create((irm https://res1.hermesagent.org.cn/install.ps1))) -SkipSetup
  ```
- 数据/代码默认落 `%LOCALAPPDATA%\hermes`（**不在 C 盘用户文档区**，合规）。

## ✅ 路线 C：PyPI 直装（已装 Python / 要定目录，备选）

### 第 0 步：确认 Python
```powershell
where.exe python; python --version; where.exe pip
```
- 版本 ≥ 3.10 且 pip 可用 → 跳到第 2 步
- 没有 Python → 走第 1 步

### 第 1 步：npmmirror 静默安装 Python 3.11.9
```powershell
Invoke-WebRequest -Uri https://registry.npmmirror.com/-/binary/python/3.11.9/python-3.11.9-amd64.exe -OutFile D:\Hermes\pysetup.exe; "DL_OK"
Start-Process -FilePath D:\Hermes\pysetup.exe -ArgumentList '/quiet','InstallAllUsers=0','PrependPath=1','TargetDir=D:\Hermes\Python' -Wait; "SETUP_DONE"
D:\Hermes\Python\python.exe --version
```
参数说明：
- `/quiet` 静默（无界面）
- `InstallAllUsers=0` 用户级安装（**非管理员必须用这个**）；管理员且要求全机可用时改 `1`
- `PrependPath=1` 自动把 Python 加进 PATH
- `TargetDir=D:\Hermes\Python` 指定安装目录（默认装到 C 盘，本项目要求 D 盘）
- `-Wait` 等安装结束再继续

> 若 npmmirror 不可达，可换华为镜像 `mirrors.huaweicloud.com/python/...` 或阿里镜像。

### 第 2 步：清华镜像安装 hermes-agent
```powershell
D:\Hermes\Python\python.exe -m pip install hermes-agent -i https://pypi.tuna.tsinghua.edu.cn/simple 2>&1 | Tee-Object D:\Hermes\pip.log; "INSTALL_FINISHED"
```
- `-i https://pypi.tuna.tsinghua.edu.cn/simple` 清华 PyPI 镜像，国内全速
- `2>&1 | Tee-Object ...` 把输出同时写日志，便于事后核对
- 尾标记 `"INSTALL_FINISHED"` 是给远控画面看的完成信号
- 预期看到大量依赖 `Successfully installed`（aiohttp / Pillow / websockets 等）

备选镜像：阿里 `https://mirrors.aliyun.com/pypi/simple/`、腾讯 `https://mirrors.cloud.tencent.com/pypi/simple/`。

### 第 3 步：PATH 持久化（用户级）
```powershell
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";D:\Hermes\Python;D:\Hermes\Python\Scripts", "User"); "PATH_OK"
```
- 写入的是**用户级** PATH，**新开的终端**才生效
- 当前终端可直接用完整路径调用：`D:\Hermes\Python\Scripts\hermes.exe`

### 第 4 步：产出不可辩驳的证据
```powershell
D:\Hermes\Python\python.exe -m pip show hermes-agent
Get-ChildItem D:\Hermes\Python\Scripts | Where-Object {$_.Name -match "hermes"} | Select-Object -ExpandProperty Name
```
预期：
```
Name: hermes-agent
Version: 0.19.0
Author: Nous Research
Location: D:\Hermes\Python\Lib\site-packages
```
```
hermes.exe
hermes-mcp.exe
hermes-auglo.exe
```

## 网络连通性判定（侦察阶段用）

```powershell
Test-NetConnection -ComputerName pypi.tuna.tsinghua.edu.cn -Port 443 -InformationLevel Quiet
Test-NetConnection -ComputerName registry.npmmirror.com   -Port 443 -InformationLevel Quiet
Test-NetConnection -ComputerName ntfy.sh                  -Port 443 -InformationLevel Quiet
```
- 一定加 `-InformationLevel Quiet`（否则输出一大段撑爆远控画面）
- 三条都 True → 走标准路线
- 清华不通 → 换阿里/腾讯镜像

## 常见报错对照

| 报错 | 原因 | 处理 |
|------|------|------|
| `无法将"python"项识别为 cmdlet` | 远程没装 Python / PATH 没生效 | 走第 1 步安装；或新开终端 |
| pip 报 SSL / 超时 | 镜像不通 | 换阿里/腾讯镜像 |
| 克隆 GitHub 全部 403 | `url.insteadOf` 被失效镜像劫持 | 清理 global+system 的 insteadOf 配置（或干脆不走 git） |
| `HTTP/2 ... PROTOCOL_ERROR` | GFW 掐 HTTP/2 | `git -c http.version=HTTP/1.1`（仅 git 路线需要） |
| `D:\Hermes is not a Hermes git checkout` | InstallDir 已存在 | 换子目录（仅官方安装器路线会遇到） |
