# 03 · 向日葵远控九大坑与应对手册

> 隔着向日葵（AweSun）操作远程电脑，本质是"盲人打字"：只能靠截图反馈。下面是实战踩出来的九大坑与对应解法。

## 坑 1 · 剪贴板同步慢一拍（粘出上一条）
**现象**：设好剪贴板后粘贴，出来的却是**上一条**内容。
**解法 · 双粘法**：
```
fpaste 文件  →  fk esc（清掉粘错的）  →  fpaste 文件  →  截图确认  →  才回车
```
更稳的两步走（避免 setc 与粘贴之间被抢焦点）：
```
setc 文件  →  sleep 3~5  →  pastein <远控窗口标题>  →  截图确认  →  fk enter
```

## 坑 2 · 剪贴板单向失效（本机→远程不推送）
**现象**：本机设了剪贴板，远程粘出来还是**远程自己的旧内容**（比如用户之前手动复制的 URL）。
**判断**：设好后粘贴，内容不是刚设的 → 剪贴板通道已废。
**解法**：立即切换下面两条通道。
- **直接键入**：先按一次 `Shift` 把远程 IME 切英文，再用 `ft <标题> <文件>` 逐字键入
- **ntfy 中继**：长内容走 base64 中转（见下）

## 坑 3 · ntfy `/raw?poll=1` 返回最早那条缓存
**现象**：上传了新内容，`/raw?poll=1` 读回来还是旧内容。
**解法**：**每次换新 topic 名**（加随机后缀），绝不复用 topic。
**附带 1**：ntfy **空 body 会发 "triggered"** —— 看到它就说明命令里变量为空或路径错。
**附带 2（★ 实战关键）**：`/raw` 会把**换行折成空格** → 注入的 `.ps1` **必须压成单行**（`;` 分隔；**禁用 `#` 注释**，因为注释会把其后整行都吃掉）。
- 本机发布：`curl -X PUT --data-binary @x.ps1 https://ntfy.sh/<topic>`
- 远程执行：`iex (irm https://ntfy.sh/<topic>/raw?poll=1)`
- 要保留换行回传：读 `/json?poll=1`（JSON 会转义 `\n`）

## 坑 4 · 中文 IME 破坏命令
**现象**：命令里的空格变连字符、`FileSystem` 变`文件系统`、字母变拼音。
**解法**：
- 命令一律写入 UTF-8（无 BOM）文件，走"文件 → 粘贴/键入"通道，**不逐字盲打**
- 直接键入前先按一次 `Shift` 切英文
- 粘贴长命令若弹出蓝色词典候选条 → `fk esc` 关掉再回车

## 坑 5 · 视频帧冻结 / 延迟
**现象**：截图停留在旧画面，或滞后 1–2 个动作。
**解法（依次尝试）**：
1. `wiggle 300 300` 晃动鼠标逼出新帧
2. 点击远控窗口内部
3. 远程执行 `cls` 或 `echo ALIVE` 强制整屏重绘
4. 最小化远控窗口再从任务栏还原
5. 按一次远程 `Win` 键（开始菜单触发整屏变化）
6. 仍冻结：**以"命令已注入 + 用另一条通道验证"为准，不死等**

## 坑 6 · 长时等待后画面彻底不刷新
**现象**：远控通道长时间无新帧（如 pip 安装期间）。
**解法**：不要靠画面判断进度；**让命令自带完成标记**（如 `"INSTALL_FINISHED"`），并以**独立回报通道**（ntfy）确认结果。

## 坑 7 · 焦点被抢（★ 逐字符键入丢字的真凶）
**现象**：文字打进了本机窗口（WorkBuddy 输入框、本地聊天框、**自己开的 python 控制台**），或远程 VIP 弹窗/浏览器推广页抢焦点；**逐字符键入时只进去一半（丢字）**。
**解法**：
- **注入脚本开头先隐藏自身控制台**：`user32.ShowWindow(user32.GetConsoleWindow(), 0)` —— 否则本机控制台不仅抢焦点，还会盖住截图区域
- **输字前校验焦点**：`GetForegroundWindow() == 远控窗口 hwnd`，不等就重新聚焦；**每 15 字符重新确认一次**
- "聚焦 + 输入"合并到同一进程（`gui.py` 的 `ft` / `fk` / `fhk` 都是先聚焦再动作）
- 必要时先清空本地输入框（`Ctrl+A` + `Delete`）
- 广告弹窗定位其关闭按钮点击关闭；**避免误按 `Ctrl+W` 关掉远控会话**
- 远控窗口因 `SetForegroundWindow` 被锁而聚焦失败 → `gui.py` 的 `focus()` 已内置 ALT 键技巧与"最小化-还原"兜底

## 坑 8 · 命令"看起来执行了"其实没落地
**现象**：盲按回车后，命令被清除/未执行。
**解法 · 验证闭环**：**注入 → 截图确认行内容 → 才回车**。远控绝不盲按。
清行技巧：`fkN <标题> backspace 60`（PowerShell 里 `Esc` 也能清行）。

## 坑 9 · 打开新终端时踩到资源管理器地址栏
**现象**：用 Explorer 地址栏跑命令，`Ctrl+A` + `Delete` 有**误删文件**风险，且行为怪异。
**解法**：改用"运行框"：
```
fhk <标题> "win+r"  →  ft <标题> q_ps.txt（内容 powershell）  →  截图确认  →  fk <标题> enter
```
若运行框回车无反应（IME 组合态吃掉），**再按一次回车**。

## 通用护栏

- **远控窗口标题通常就是识别码**（形如 `<9位数字>`）；class 含 `FlutterMultiWindow` / `ORAY_FLUTTER_VIEW_CONTAINER`
- 每条命令尾部加完成标记（`"XXX_DONE"`），便于截图判定
- 截图看不清时用 `cropregion.py x1 y1 x2 y2 scale` 放大关键区域（坐标用逻辑桌面空间，如 1280x720）
- 状态回传优先走 ntfy，不依赖画面：`Invoke-RestMethod -Uri 'https://ntfy.sh/<topic>' -Method Post -Body $x`
